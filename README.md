# 🎮 Jogo de Adivinhação - JavaScript

Este repositório contém um projeto simples e divertido desenvolvido com **HTML**, **CSS** e **JavaScript**: um **jogo de adivinhação**, onde o jogador precisa descobrir qual número o computador escolheu aleatoriamente entre 1 e 100.

## 🧠 Como funciona?

O jogador deve inserir um número e o sistema informará se o palpite foi **muito alto** ou **muito baixo**. O jogo continua até o número correto ser descoberto ou o limite de tentativas ser atingido. O sistema também registra o **recorde de menor número de tentativas** usando `localStorage`.

## 🛠️ Funcionalidades

- Geração aleatória de número entre 1 e 100
- Validação de entrada do usuário
- Feedback imediato ao jogador
- Limite de tentativas para vencer o jogo
- Registro de recorde de menor número de tentativas
- Botão para reiniciar o jogo

## 💡 Conceitos aplicados

- Declaração e uso de **variáveis**
- Estruturas de decisão com `if` e `else`
- Laços de repetição com `while` e uso de **funções**
- Operadores **lógicos** e **relacionais**
- Manipulação de DOM (HTML via JavaScript)
- Armazenamento local com `localStorage`

## 📁 Estrutura do Projeto

- `index.html` — Estrutura principal da página
- `style.css` — Estilo visual do jogo
- `script.js` (incluso no HTML) — Lógica do jogo
